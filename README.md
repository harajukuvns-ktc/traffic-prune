# Traffic Prune

Webgame về giao thông đường phố Việt Nam: bạn lái xe máy giao hàng trong một khu phố, đi đúng luật thì được thưởng, vi phạm thì bị phạt theo mức phạt thật, phải đền cho người bị ảnh hưởng, và bị người trong phố nhắc nhở theo kiểu hài hước.

**Chơi thử:** tải cả thư mục về rồi nháy đúp `index.html`, hoặc chạy `python -m http.server 8000` trong thư mục này và mở http://localhost:8000.

- Hướng dẫn cài đặt và cách chơi: [HUONG-DAN.md](HUONG-DAN.md)
- Tài liệu thiết kế (đọc trước khi sửa code): [docs/THIET-KE.md](docs/THIET-KE.md)
- Kiểm tra tự động: `cd tests && node kiem-tra-logic.js ../index.html`

Mức phạt lấy theo Nghị định 168/2024/NĐ-CP (đã sửa đổi bởi Nghị định 238/2026/NĐ-CP). Game mang tính giáo dục, không thay thế văn bản pháp luật.
